## 2024-06-25 - High-Frequency DOM Updates Optimization
**Learning:** Found a performance bottleneck where jQuery's `.css()` method was being called unconditionally in the main animation loop (`_step` -> `_draw`) even when the frame hadn't changed. Furthermore, `.css()` in jQuery creates unnecessary object allocations and overhead compared to direct DOM style manipulation (`element.style.propertyName`) which is much faster for hot loops.
**Action:** Replaced `.css()` calls with direct `style` property manipulation in `src/animator.js` `_draw` function, and added a conditional check to skip redrawing entirely if `frameChanged` is false in `_step`. Next time I'm optimizing a highly active rendering loop, I will prioritize vanilla JS DOM updates over jQuery and look for opportunities to skip redundant redraws.
